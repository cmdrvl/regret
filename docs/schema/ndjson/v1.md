# regret NDJSON schema v1

This document defines the stable NDJSON contract for `regret --ndjson` (schema_version = 1).

## Record ordering
1. `meta` (exactly one)
2. `diag` (zero or more; only when `--debug`)
3. `stat` (fixed order by name)
4. `rank` (sorted by score desc, then culprit_sha)
5. `evidence` (grouped by culprit_sha, then evidence_time desc, then evidence_sha)

## Record types

### meta
Fields:
- `type`: `"meta"`
- `schema_version`: `1`
- `tool_version`: semver string
- `repo_id`: blake3 hex of canonical git_common_dir
- `repo_basename`: last path component of repo root
- `selected_branch`: resolved branch ref (stable)
- `window_since_utc`: ISO-8601 or `null` when unbounded
- `window_until_utc`: ISO-8601
- `window_until_source`: `flag` | `github_actions_head_committer_time` | `wall_clock`
- `coverage_since_utc`: ISO-8601 or `null` when unknown
- `coverage_valid`: boolean
- `cache_valid`: boolean

### stat
Fields:
- `type`: `"stat"`
- `name`: `regret_events` | `max_score` | `events_per_100_commits` | `commits_in_window` | `coverage_days`
- `value`: number

### rank
Fields:
- `type`: `"rank"`
- `culprit_sha`: full 40-hex SHA
- `score`: integer
- `events`: integer
- `ttr_p50_h`: float
- `culprit_time_utc`: ISO-8601
- `surface_coverage`: float in `[0.0, 1.0]` (optional; omitted if unknown)

### evidence
Fields:
- `type`: `"evidence"`
- `culprit_sha`: full 40-hex SHA
- `evidence_sha`: full 40-hex SHA
- `signal_type`: `revert` | `linked_fix`
- `confidence`: float in `[0.0, 1.0]`
- `confidence_reason`: `canonical_revert_line` | `patch_id_equivalence` | `explicit_trailer`
- `time_to_regret_hours`: float
- `work_ref`: string (optional)
- `bead_ref`: string (optional)
- `session_ref`: string (optional)

### diag
Fields:
- `type`: `"diag"`
- `name`: string
- `value`: JSON value

Emitted only when `--debug` is set. Current `name` values:
- `scan_status` (`"ran"` | `"skipped"`) and `new_commits` (integer) in default ranking mode
- `mode` (`"explain"`) in explain mode
